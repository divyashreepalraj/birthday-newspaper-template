# 🎉 Birthday Newspaper Invitation Template

A modern **Birthday Invitation Template** inspired by a classic newspaper front page. Built using only **HTML5** and **CSS3**, this template is fully responsive and easy to customize for birthdays, parties, or special celebrations.

---

## 📸 Preview

![Birthday Invitation Preview](./assets/Ref%20Image.png)

---

## ✨ Features

- 📰 Newspaper-inspired invitation layout
- 📱 Fully Responsive Design
- 🎨 Clean and Minimal UI
- ⚡ Built with HTML5 & CSS3
- 🖼️ Easy to replace images
- 📝 Easily editable text content
- 💻 Lightweight and beginner-friendly
- 🚀 No frameworks or libraries required

- HTML5

- Media Queries

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/divyashreepalraj/birthday-newspaper-template.git
```

### Open the Project

Simply open the `index.html` file in your preferred web browser.

No installation or build process is required.

---

## 🎨 Customization

You can easily personalize the template by updating:

- Birthday person's name
- Event date and time
- RSVP information
- Invitation message
- Images inside the `assets` folder
- Colors and fonts in `style.css`

---

## 📱 Responsive Design

The template is optimized for:

- Desktop
- Laptop
- Tablet
- Mobile Devices

---

## 📷 Replace Images

Replace the following files inside the `assets` folder:

```
image1.png
image2.png
```

Or update the image paths in `index.html`.
